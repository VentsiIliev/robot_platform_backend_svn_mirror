# Стъпка 3: Инсталиране на роботизирания софтуер

## Получаване на пакета

Получете от администратора одобрената версия за `paint_tray_dry` и адреса
за изтегляне. Изтеглете двата файла за една и съща версия:

```text
paint_tray_dry-robot-VERSION-x86_64.tar.gz
paint_tray_dry-robot-VERSION-x86_64.tar.gz.sha256
```

`VERSION` е обозначение, което трябва да замените с предоставения номер.
Адресът за производствено изтегляне още не е попълнен в това ръководство.
За частно хранилище използвайте предоставения достъп, без да записвате
пароли или токени в командите и документацията.

## Проверка и първа инсталация

Работете като нормалния потребител на Ubuntu, например `pl_user`.
Изпълнете командите в терминала. Не стартирайте целия Python инсталатор
със `sudo`; той ще поиска администраторска парола за нужните стъпки.

Първо създайте папката и поставете изтеглените два файла в нея:

```bash
mkdir -p ~/robot-install
cd ~/robot-install
```

Заменете `VERSION` с одобрената версия във всяка команда:

```bash
sha256sum -c paint_tray_dry-robot-VERSION-x86_64.tar.gz.sha256
```

Продължете само ако резултатът е `OK`:

```bash
tar -xzf paint_tray_dry-robot-VERSION-x86_64.tar.gz
set -o pipefail
python3 -B robot/install.py 2>&1 | tee install.log
echo "Installer exit code: $?"
```

Успешната инсталация завършва с код `0`. При първа инсталация се
подготвят системните зависимости, SSH, дистанционната поддръжка,
GNOME Kiosk и услугата за обновяване. Автоматичният вход е включен
по подразбиране. При първата киоск инсталация общата парола за
контролиран изход се задава автоматично чрез защитения хеш, включен в
production пакета. Всички нови машини получават една и съща парола, а
последващите инсталации запазват локално сменения хеш.
Инсталаторът не прекъсва текущата сесия.

Ако първо трябва да проверите ръчно входа в kiosk сесията, вместо
основната команда използвайте:

```bash
python3 -B robot/install.py --kiosk manual
```

Ако системната подготовка се прекъсне, запазете `install.log` и повторете
инсталатора. Не приемайте съобщението за инсталиран launcher като
доказателство, че всички системни стъпки са завършили. При необходимост
администраторът може изрично да повтори подготовката с
`--setup-system --kiosk enabled`.

## Проверка след инсталиране

Когато роботът е спрян и сте готови, рестартирайте:

```bash
sudo reboot
```

При автоматичен вход приложението трябва да стартира. При ръчен вход
изберете **Kiosk Script Session (X11 Display Server)** от менюто за сесия
на екрана за вход. Не спирайте `gdm3` за тази проверка.

В терминал или SSH проверете услугата:

```bash
systemctl --user is-active robot-update-paint_tray_dry.service
```

Очакваният резултат е `active`. Проверете версиите:

```bash
python3 - <<'PY'
import json
from pathlib import Path
root = Path.home() / '.local/share/robot-releases/paint_tray_dry'
m = json.loads((root / 'current/manifest.json').read_text())
print('Robot:', m['version'])
print('Platform:', m['selection']['platform_version'])
print('Backend:', m['selection']['backend_version'])
PY
```

Версиите трябва да съответстват на одобрения пакет. Настройките на робота,
адресите на устройствата, правата за хардуерен достъп и производствената
проверка се извършват отделно за конкретната машина.

Продължете с [обновяване на системата](updates.md).
