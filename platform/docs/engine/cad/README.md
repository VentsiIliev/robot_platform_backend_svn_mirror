# `src/engine/cad/` — Reserved directory

This checkout contains an empty CAD directory: no Python module or public engine CAD service is implemented here. DXF and contour authoring currently use the workpiece editor and paint workpiece/schema adapters. Do not import a CAD service from this path or describe it as an implemented subsystem.

See [workpiece editor](../../applications/workpiece_editor/README.md) and [paint domain](../../robot_systems/paint/domain/README.md).
