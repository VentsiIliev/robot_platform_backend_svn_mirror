# Root `bootstrap/` — Reserved environment directory

The root `bootstrap/` directory is empty in this checkout. It is distinct from [runtime bootstrap](../bootstrap/README.md), implemented under `src/bootstrap/`. There are no environment setup scripts or Python APIs here.

Use [packaging](../packaging/README.md) and the root requirements file for installation guidance; ROS/backend/OS dependencies remain separate from Python dependencies.
